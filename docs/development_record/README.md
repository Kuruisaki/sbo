# Kuruisaki/sbo 项目开发归档

归档日期：2026-10-15（Asia/Shanghai）。代码快照：`d670b51fb0bc1089f46677e6852a055902c28dee`，分支 `main`，本地远端引用 `origin/main`。项目地址：[Kuruisaki/sbo](https://github.com/Kuruisaki/sbo)。

这个项目想回答一个具体问题：**在厚度和升力要求不变的情况下，怎样调整 NACA 2412 翼型的弯曲程度和弯曲位置，让阻力更小？**

程序先用 XFOIL 计算一批翼型，再用这些结果训练一个计算很快的预测模型。模型建议下一种值得尝试的翼型，XFOIL 再去计算它；新结果加入训练集后，模型重新学习。如此反复，最后再用独立数据和更细的面元检查推荐方案是否可靠。这就是本项目的“基于代理模型的优化”（SBO）。

你可以把它理解为“先做一批试验 → 总结规律 → 挑下一次试验 → 用新结果修正规律 → 最后独立验收”。这里的试验是 XFOIL 数值计算。文中的“高保真”表示它比代理模型更直接地求解气动问题，并不表示它等同于风洞试验或三维飞机的真实表现。

## 先认识这些词

| 文中用语 | 在本项目中是什么意思 |
|---|---|
| 基准翼型（baseline） | 改进前的 NACA 2412；所有收益都要与它比较 |
| 设计变量 m、p | m 控制中弧线的最大弯度，p 控制最大弯度的位置；厚度参数 t 固定为 0.12 |
| CD、CL、Cp | 分别是阻力系数、升力系数和表面压力系数；目标是在 CL=0.5 时减小 CD |
| 面元（panel） | XFOIL 把翼型表面划分成的小段；用不同数量计算，可以检查结果对划分精细程度是否敏感 |
| DOE / LHS | DOE 是安排初始试验点；LHS 是让这些点在各变量范围内较均匀分布的一种采样方法 |
| 代理模型 / GP | 用已有计算结果训练的预测器；本项目采用高斯过程（GP），同时给出预测值和不确定性 |
| LOO | 轮流拿出一个训练点，用其余点预测它，检查模型是否稳定 |
| EI / 探索 | EI 衡量一个新点可能带来的改进；探索则主动尝试训练点稀疏的区域 |
| proposal | 模型建议的下一组参数；尚未经过 XFOIL 计算，不能直接称为最优结果 |
| holdout | 预先留出的独立测试点；它们的计算结果不参与训练和选点，最后才用于检验模型 |
| run / run-id | 一次完整实验及其名字；同一实验的各阶段共享一个运行目录 |
| hash / 冻结 / resume | hash 是检查内容是否变化的“指纹”；冻结是固定本次输入或模型；resume 是核对记录后接着做 |

第一次阅读不必记住全部缩写。正文会在关键步骤再解释它们；函数名和配置字段保留英文，方便你找到代码。

## 已完成的主实验：算了多少次，得到了什么

主实验：`runs/m1_20261013_02/`。这些产物本地存在，但 `runs/` 被 Git 忽略，不能假定 GitHub checkout 同时含有它们。

| 阶段结束时 | 可训练点 | 留出点 | 累计 XFOIL 启动 | 不同标准设计 | 模型/结果 |
|---|---:|---:|---:|---:|---|
| M1 | 1 | 0 | 6 | 1 | 基准 CD160=.00599；额外五次独立调用通过 |
| M2 基准关卡 | 1 | 0 | 9 | 1 | 200/240 与重复160通过 |
| M2 DOE | 17 | 6 | 31 | 23 | 16 LHS+基准、6 留出，无失败替补 |
| M3 | 17 | 6 | 31 | 23 | `iter_000`，仅提出候选，新增求解为0 |
| M4 | 25 | 6 | 39 | 31 | 成功新增8点，`iter_008`，`converged` |
| M5 | 25 | 6 | 51 | 31 | 12次独立复核，训练与最终GP不变 |

先看结论：在相同的 240 面元计算条件下，推荐翼型的阻力系数从 0.00600 降为 0.00545，约降低 **9.17%**。这个结论只针对当前固定工况和验收规则，不是任意飞行条件下都能降低同样比例，也不是全局最优的证明。

以下保留精确数值，便于对照原始文件。MAE 是平均绝对预测误差，越小越好；RMSE 会更重地计入较大的误差。独立 holdout MAE=`5.126022731267102e-5`，门槛 `.0002995`；RMSE=`8.17384801704801e-5`，R²=`.9384112746624128`，均值±2σ覆盖6/6（只作诊断）。推荐 `m=.024420712821516033,p=.4881333427216427,t=.12`；CD240 从基准 `.00600` 降到 `.00545`，同精度改善约9.17%，`.00055` 大于两者 ε 之和约 `.00002`。

测试过程中先出现过失败，修复后又重跑了受影响的测试。按每个测试最后一次保存的结果统计：合计300个不同测试最终通过，其中288个单元测试、12个 integration。不是声称某一次全套运行300项全部一次通过；完整失败和复测证据仍保留。
